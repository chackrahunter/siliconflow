# Security policy

SiliconFlow is a local, client-side Minecraft mod. Please do not publish sensitive logs, world paths, account data, or private diagnostic output in an issue.

## Reporting a vulnerability

For a security issue in the code or release process, use GitHub's private **Report a vulnerability** action on the repository when available. If that channel is unavailable, open a minimal issue asking for a private contact path; do not include exploit details or sensitive data.

Supported security context: the current beta artifact targets Minecraft 1.21.4, Java 21+, Fabric Loader 0.16.14, and Fabric API 0.119.4+1.21.4.
